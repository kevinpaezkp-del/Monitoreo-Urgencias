# Monitor de Flujo de Urgencias — Demo

Prototipo conceptual para Health Tank 2026.

## Qué muestra

- Flujo simulado de pacientes en Urgencias.
- Eventos automáticos cada 30 segundos.
- Cambios en laboratorio, imágenes e interconsultas.
- Alertas de redefinición, radiología, resultados críticos y egreso.
- Pacientes que ingresan, avanzan y egresan.
- Priorización dinámica por oportunidad de acción.
- Línea de tiempo individual por paciente.

> Todos los pacientes y datos de esta demo son simulados. No contiene información clínica real.

## Publicación

El sitio está diseñado para funcionar directamente con GitHub Pages desde la rama `main` y la raíz del repositorio.

Archivos principales:

- `index.html`
- `styles.css`
- `app.js`

## Objetivo

Mostrar cómo una futura integración de Servinte, Athenea y Radiología podría convertir eventos clínicos y operativos en alertas accionables para reducir el “tiempo invisible” en Urgencias.
