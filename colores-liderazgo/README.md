# Colores de liderazgo — Simulador interactivo

**Abrir app:** https://kevinpaezkp-del.github.io/Monitoreo-Urgencias/colores-liderazgo/

Aplicación web independiente para una dinámica de estilos de liderazgo de LaCardio. Se publica desde la carpeta `colores-liderazgo/` en el repositorio GitHub Pages existente `kevinpaezkp-del/Monitoreo-Urgencias`, sin modificar el monitor de urgencias.

## Cómo participar

1. Abrir el enlace en el teléfono.
2. Pulsar **Descubrir mis colores**.
3. Seleccionar de 8 a 12 palabras que describan cómo actúas habitualmente (puedes buscar, añadir o quitar).
4. Pulsar **Ver mi resultado** para conocer tu distribución rojo/azul/verde/amarillo, interpretaciones y oportunidades de crecimiento.
5. Opcionalmente compartir el resultado con la opción nativa del teléfono o copiarlo.

## Cómo funciona

- Interfaz 100 % adaptable a celular; no requiere instalar aplicaciones.
- Incluye las mismas 65 características y asociaciones de colores del archivo original `Simulador Colores.html`.
- Cada característica seleccionada suma un punto al color asociado.
- Se muestran porcentajes por color y se reconocen empates como combinaciones equilibradas.
- Soporta 20 o más participantes simultáneos porque cada persona calcula el resultado en su propio dispositivo.
- No guarda respuestas ni recopila datos personales; **no** existe consolidado de resultados del grupo.
- Dinámica de autoconocimiento orientativa, **no** instrumento psicológico validado.

## Archivos y mantenimiento

El proyecto se encuentra íntegramente en `index.html` (HTML, CSS y JavaScript sin dependencias externas). Para editar etiquetas, descripciones o estilos, modifica ese archivo en GitHub: la publicación de GitHub Pages se actualiza después de guardar cambios en `main`.
